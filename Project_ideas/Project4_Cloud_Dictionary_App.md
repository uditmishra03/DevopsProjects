# Project 4: Serverless Cloud Dictionary Application

## Overview
Build a serverless dictionary application using React, AWS Amplify, DynamoDB, and Lambda for searching cloud terms and definitions.

## Architecture Components
- **Frontend**: Pre-built React application
- **Hosting**: AWS Amplify for frontend deployment
- **Database**: DynamoDB for terms and definitions storage
- **Compute**: Lambda function for search functionality
- **API**: API Gateway for Lambda integration

## Implementation Steps

### 1. Frontend Setup
- Clone pre-built React application
- Host application on AWS Amplify

### 2. Database Configuration
- Create DynamoDB table for dictionary data
- Upload pre-written terms and definitions using AWS CLI

### 3. Lambda Function Development
- Create Lambda function for definition retrieval
- Implement search logic for DynamoDB queries

### 4. API Integration
- Set up API Gateway endpoints
- Connect Lambda function to API
- Ensure search terms pass through correctly

### 5. Application Deployment
- Sync all components together
- Deploy complete application
- Test search functionality

## Project Specifications
- **Estimated Time**: 2-3 hours
- **Cost**: Free within AWS free tier
- **Target Skills**: API-driven applications, serverless design

1. **Internal Knowledge Databases**: Help new employees with technical terms and acronyms
2. **Educational Glossaries**: Interactive learning tools for students with instant definitions
